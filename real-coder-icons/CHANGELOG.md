# Changelog

## 5.37.0 — Real Coder Icons (initial fork)

Real Coder Icons is a fork inspired by the [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)
(Philipp Kief / Material Extensions, MIT). This first release rebrands the
extension and adds NeoObjectPascal support.

### Added

- **NeoObjectPascal file icons**: dedicated icon for `*.npas` (RC neon monogram)
  and `*.test.npas` (RC monogram with a test badge).
- Real Coder Icons neon branding: logo, gallery banner (`#0D0D0D`), display name,
  commands and settings under the `realcoder-icons.*` namespace.

### Changed

- Rebranded from Material Icon Theme to **Real Coder Icons** across the extension
  identity, commands, settings, localization and documentation.
- Icon-theme manifest is generated to `dist/realcoder-icons.json`.

### Credits

The original icon set and generator architecture are by the Material Icon Theme
project and remain under its MIT license (see `LICENSE`).
